## Basic concepts of C++

### Initializers

```cpp
// Copy initialization
int a = 1;
// Direct initialization - Old C
int a(1);
// Brace initialization - braces with value (Modern C++)
int a{1};
// Value initialization - braces without value (actually with default value)
int a{}; // --> a == 0
```
