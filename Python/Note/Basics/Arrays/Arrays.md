# Python Arrays

## Dictionary

- Just as its name, dictionary type in Python consists of many words and their definitions, formally keys and their values or genearlly data values.
- Dictionary items are ordered, changable, and cannot be duplicated.

In Python, to create a dictionary, we put forth a name for the dictionary then assign it with data values enclosed in curly brackets. Each item is separated by a commma.

```python
myDict = {
    "valedictorian": "A student who has excellent performance in their instiution.",
    "Hello": "A way to greet people",
    "Exuberant": "being lively, possessing a huge amount of energy"
}
```
